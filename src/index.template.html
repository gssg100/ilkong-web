태동 세기 👣

첫 태동이 느껴지면 큰 버튼을 눌러 줘
0

표준 방법은 10회 세기예요. 태동이 활발한 시간에 옆으로 누워 10회를 느낄 때까지 걸린 시간을 재요. 보통 2시간 안에 채워져요. 태동은 정상 횟수가 따로 정해져 있지 않고 평소 패턴이 중요해요. 평소보다 움직임이 줄거나 달라졌다면 횟수를 채우려고 기다리지 말고 바로 의료진에게 문의해 주세요. 세다가 닫아도 이 기기에 저장돼서 이어서 셀 수 있어요.

저장공간 정리 🧹

삭제한 기록의 사진은 복구를 위해 일정 기간 보관돼. 보관 기간이 지난 사진은 아래 버튼으로 직접 정리할 수 있어. 자동 삭제되는 건 아니야.

PIN 변경 🔒

로그인할 때 쓰는 숫자 4~12자리를 바꿔. 상대방 것은 각자 폰에서 바꾸면 돼.

실시간 푸시 알림 🔔

앱이 닫혀 있거나 화면이 꺼져 있어도 상대방의 새 글·사진·댓글 소식을 휴대폰 알림으로 바로 받을 수 있어.

세부 알림 항목

기록 데이터 내보내기 💾 (사진 원본 별도)

기록·댓글 정보와 사진 목록을 JSON 파일로 받을 수 있어. 사진 원본은 Supabase Storage에 별도로 저장되며 파일에 포함되지 않아. 앱 전체를 복구하는 완전 백업은 아니야.

관리자 전체 백업 · 복원 점검 🛡️

서버 DB와 사진 원본을 따로 보관하고 복원 검증하는 관리자용 도구를 준비했어. 2026.10.14에는 통합 백업 모의 성공·오류 차단과 비운영 복원 대상 확인 절차도 강화했어. 이 기기의 JSON 내보내기와는 별개야.

현재 실제 운영 DB·사진 전체 백업과 별도 환경의 실복원 완료는 확인되지 않았어. 이 화면은 관리자 백업 성공 여부를 실시간으로 확인하지 못하니 운영 기록에서 검증해 줘.
